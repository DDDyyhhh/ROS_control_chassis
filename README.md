# 3D SLAM and Navigation Project: OrangePi 5 Plus with Unitree L2 LiDAR and Fast-Planner

## 1. Project Overview

This project implements a real-time **3D SLAM (Simultaneous Localization and Mapping)** and **3D Autonomous Navigation** system on an embedded platform, the **OrangePi 5 Plus**, utilizing the **Unitree L2** LiDAR.

The system is composed of two primary modules:
*   **SLAM Module**: A customized version of the high-performance LiDAR-Inertial Odometry framework, **Point-LIO** (`point_lio_unilidar`), is used to generate a high-precision 3D point cloud map and provide accurate localization in real-time.
*   **Navigation Module**: The cutting-edge motion planning framework, **Fast-Planner**, is employed for dynamic path planning and obstacle avoidance within the map generated by the SLAM module, guiding the robot to its destination autonomously.

The entire system has been meticulously configured and debugged to ensure smooth operation on resource-constrained embedded hardware.

## 2. System Architecture and Data Flow

```
+------------------+     /unilidar/cloud      +----------------------+
| Unitree L2 LiDAR | -- /unilidar/imu ------> | Point-LIO SLAM       |
| Driver           |                          | (laserMapping_STM32) |
+------------------+                          +----------------------+
                                                         |
                                                         | 1. /pointlio/odom (Odometry)
                                                         | 2. /pointlio/cloud_registered (Global Map)
                                                         | 3. /pointlio/cloud_registered_body (Local Perception Cloud)
                                                         | 4. TF: map -> odom -> base_link
                                                         |
         +-----------------------------------------------V------------------------------------------------+
         |                                                                                                 |
+--------V---------+      /move_base_simple/goal      +---------------------+     /fast_planner_node/pos_cmd     +-----------+
| Rviz Visualization & | <-------------------------------- |    Fast-Planner     | ---------------------------------> | Controller|
| Goal Publishing    |                                   | (plan_manage)       |                                    | (so3_ctrl)|
+------------------+                                   +---------------------+                                    +-----------+
                                                                                                                      | /cmd_vel
                                                                                                                      V
                                                                                                               +-------------+
                                                                                                               | Robot Base  |
                                                                                                               | (STM32)     |
                                                                                                               +-------------+
```

## 5. Key Configurations

Before running the system, ensure the following configuration files match your hardware setup.

*   **LiDAR Driver Config**:
    *   File: `~/catkin_ws/src/unitree_lidar_ros/config/config.yaml`
    *   Check: `serial_port` must match the actual serial port used by your LiDAR (e.g., `/dev/ttyACM0`).

*   **Point-LIO SLAM Config**:
    *   File: `~/catkin_ws/src/point_lio_unilidar/config/unilidar_l2_STM32.yaml`
    *   Check: `lid_topic` and `imu_topic` should match the topics published by the LiDAR driver (expected to be `/unilidar/cloud` and `/unilidar/imu`).
    *   Check: The LiDAR-IMU extrinsics `extrinT` and `extrinR` must be correct.

*   **Fast-Planner Config**:
    *   File: `~/catkin_ws/src/car_test/params/final_params.yaml`
    *   Check: `odom_topic` must be set to `/pointlio/odom`.
    *   Check: `map/frame_id` must be set to `map`.
    *   Check: `camera_to_body` or similar extrinsics to ensure Fast-Planner knows the LiDAR's position on the robot.

## 6. How to Run

1.  **Source the Environment**:
    In a new terminal, source the workspace environment.
    ```bash
    cd ~/catkin_ws
    source devel/setup.bash
    ```

2.  **Launch the Main System**:
    Run the main launch file that integrates all modules.
    ```bash
    # Replace car_test and main.launch with your actual package and file names
    roslaunch car_test main.launch
    ```
    This will start the LiDAR driver, SLAM, Fast-Planner, controller interface, and Rviz.

3.  **Interact with Rviz**:
    *   **Check Status**: The Rviz window will open automatically.
        *   In the `Global Options` panel on the left, set `Fixed Frame` to `map`.
        *   Verify that the `TF` tree is correct (map -> odom -> base_link -> ...).
    *   **Observe Mapping**:
        *   Add a `PointCloud2` display in Rviz and subscribe to the `/pointlio/cloud_registered` topic.
        *   Manually drive the robot around. You should see the 3D point cloud map being built in real-time.
    *   **Autonomous Navigation**:
        *   Click the **"2D Nav Goal"** button in the top toolbar of Rviz.
        *   Click on an obstacle-free area in the map where you want the robot to go. Drag the arrow to set the final orientation.
        *   Upon releasing the mouse button, Fast-Planner will plan a path, and the robot will start moving towards the goal.

## 7. Troubleshooting

*   **Build Fails**:
    *   **`Cannot find -lpose_utils`**: This is caused by improper linking in `CMakeLists.txt` files. Edit the `target_link_libraries` section to use the `${catkin_LIBRARIES}` variable.
    *   **C++ Compilation Errors (especially in `multi_map_server.cc`)**: API mismatch between outdated source code and newer libraries. The quickest fix is to comment out the compilation of this node in the `multi_map_server` package's `CMakeLists.txt`.

*   **TF Tree Errors**:
    *   **Cause**: Multiple nodes are publishing the same TF transform (e.g., `odom` -> `base_link`).
    *   **Solution**: Ensure that only the `laserMapping_STM32` (Point-LIO) node publishes the `map`->`odom` and `odom`->`base_link` transforms by correcting its `publish_odometry` function.

*   **No Map Displayed in Rviz**:
    *   **Cause**: The display is not added or configured correctly in Rviz.
    *   **Solution**: Manually add a `PointCloud2` display and set its topic to `/pointlio/cloud_registered`.

*   **Fast-Planner Does Not Plan a Path**:
    *   **Cause**: Incorrect map input topic.
    *   **Solution**: Verify the `<remap>` rule in your main launch file. The map input for Fast-Planner (`/sdf_map/cloud`) must be remapped to the real-time local point cloud topic, `/pointlio/cloud_registered_body`.

# 3D SLAM与导航项目：基于OrangePi 5 Plus、宇树L2激光雷达与Fast-Planner

## 1. 项目概述

本项目旨在嵌入式平台 **OrangePi 5 Plus** 上，利用 **宇树 (Unitree) L2** 激光雷达，实现实时的 **3D SLAM（同步定位与建图）** 与 **3D自主导航** 功能。

系统核心由两大部分组成：
*   **SLAM模块**: 采用高性能的激光雷达-惯性里程计框架 **Point-LIO** 的定制版本 (`point_lio_unilidar`)，负责实时生成高精度3D点云地图并提供精确的定位。
*   **导航模块**: 采用前沿的运动规划框架 **Fast-Planner**，负责在SLAM建立的地图中进行动态路径规划和避障，引导机器人自主到达目标点。

整个系统经过精心配置和调试，以确保在资源受限的嵌入式硬件上流畅运行。

## 7. 故障排查

*   **编译失败**:
    *   **找不到 `-lpose_utils`**: 这是因为多个包的 `CMakeLists.txt` 文件链接库的方式不规范。请参考我们的调试记录，修改 `target_link_libraries` 部分，使用 `${catkin_LIBRARIES}`。
    *   **C++编译错误 (尤其在 `multi_map_server.cc`)**: 代码API版本与库不匹配。最快的解决方法是在 `multi_map_server` 包的 `CMakeLists.txt` 中注释掉对该节点的编译。

*   **TF树错误**:
    *   **原因**: 多个节点发布了相同的TF变换（如 `odom` -> `base_link`）。
    *   **解决**: 确保只有 `laserMapping_STM32` (Point-LIO) 节点发布 `map`->`odom` 和 `odom`->`base_link` 的变换，修正其 `publish_odometry` 函数。

*   **Rviz中无地图显示**:
    *   **原因**: 没有在Rviz中添加并正确配置显示器。
    *   **解决**: 手动添加一个 `PointCloud2` 类型的显示器，并将其订阅的话题设置为 `/pointlio/cloud_registered`。

*   **Fast-Planner不规划路径**:
    *   **原因**: 地图输入话题错误。
    *   **解决**: 确认主Launch文件中的 `<remap>` 规则，将Fast-Planner的地图输入 (`/sdf_map/cloud`) 重映射到实时的局部点云话题 `/pointlio/cloud_registered_body`。
